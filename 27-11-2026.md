
# 🐧 Linux Fundamentals and Basic System Administration

## 1. Linux Fundamentals

### 1.1 What is Linux?

Linux is an open-source operating system kernel that manages hardware resources and provides services for applications.

Linux-based operating systems are widely used in:
- Servers and cloud computing.
- DevOps and automation.
- Software development.
- Containerization.
- Networking.
- High-performance computing.

Examples of Linux-based operating systems include Ubuntu, Red Hat Enterprise Linux (RHEL), Debian, Fedora, and Rocky Linux.

### 1.2 Linux Architecture and Kernel

Linux architecture consists of several layers.

```text
+-----------------------------+
|       User Applications     |
+-----------------------------+
|       Shell / Utilities     |
+-----------------------------+
|        System Libraries     |
+-----------------------------+
|         Linux Kernel        |
+-----------------------------+
|           Hardware          |
+-----------------------------+
```

**Hardware:** Physical components such as CPU, RAM, storage, and network devices.

**Kernel:** The core component of Linux. It manages processes, memory, devices, filesystems, and networking.

**System Libraries:** Provide interfaces that applications use to interact with system services.

**Shell:** Provides a command-line interface for interacting with the operating system.

**User Applications:** Programs and services that users execute.

Important kernel responsibilities:
- Process management.
- Memory management.
- Device management.
- Filesystem management.
- Network management.
- Security and access control.

Check the kernel version:

```bash
uname -r
```

Display complete system information:

```bash
uname -a
```

### 1.3 Linux Distributions

A Linux distribution combines the Linux kernel with system utilities, package managers, libraries, and applications.

Common distributions:

| Distribution | Package Manager | Package Format |
|---|---|---|
| Ubuntu | APT | DEB |
| Debian | APT | DEB |
| Red Hat Enterprise Linux | DNF | RPM |
| Fedora | DNF | RPM |
| Rocky Linux | DNF | RPM |

**Ubuntu:** Commonly used for development, servers, and cloud environments.

**Red Hat Enterprise Linux:** An enterprise-focused distribution used in business and production environments.

Check the installed distribution:

```bash
cat /etc/os-release
```

### 1.4 Shell vs Terminal

A terminal is an interface through which users interact with a command-line environment.

A shell is a program that interprets commands and executes them.

Examples of shells:
- Bash.
- Zsh.
- Fish.
- Dash.

Check the current shell:

```bash
echo $SHELL
```

Check the current user:

```bash
whoami
```

### 1.5 Absolute and Relative Paths

An absolute path specifies the complete location of a file or directory starting from the root directory `/`.

Example:

```bash
/home/user/Documents/file.txt
```

A relative path specifies a location relative to the current working directory.

Example:

```bash
Documents/file.txt
```

Important path symbols:

| Symbol | Meaning |
|---|---|
| `/` | Root directory |
| `~` | Current user's home directory |
| `.` | Current directory |
| `..` | Parent directory |

Display the current working directory:

```bash
pwd
```

Navigate to the home directory:

```bash
cd ~
```

Navigate to the parent directory:

```bash
cd ..
```

## 2. File and Directory Management

### 2.1 Linux Directory Structure

Linux uses a hierarchical filesystem structure that starts from the root directory `/`.

Important directories:

| Directory | Purpose |
|---|---|
| `/` | Root of the filesystem |
| `/home` | User home directories |
| `/root` | Root user's home directory |
| `/etc` | System configuration files |
| `/var` | Variable data and logs |
| `/tmp` | Temporary files |
| `/bin` | Essential user commands |
| `/sbin` | System administration commands |
| `/usr` | User applications and shared resources |
| `/opt` | Optional application software |
| `/dev` | Device files |
| `/proc` | Process and kernel information |
| `/boot` | Boot-related files |

Explore the root directory:

```bash
ls /
```

View directory contents:

```bash
ls -la
```

### 2.2 Creating Files and Directories

Create a directory:

```bash
mkdir linux-practice
```

Create nested directories:

```bash
mkdir -p linux-practice/files/documents
```

Create an empty file:

```bash
touch sample.txt
```

Create multiple files:

```bash
touch file1.txt file2.txt file3.txt
```

### 2.3 Copying Files and Directories

Copy a file:

```bash
cp sample.txt backup.txt
```

Copy a file into another directory:

```bash
cp sample.txt linux-practice/
```

Copy a directory recursively:

```bash
cp -r linux-practice linux-backup
```

### 2.4 Moving and Renaming Files

Move a file:

```bash
mv sample.txt linux-practice/
```

Rename a file:

```bash
mv backup.txt backup-old.txt
```

Move a directory:

```bash
mv linux-practice linux-project
```

### 2.5 Deleting Files and Directories

Delete a file:

```bash
rm sample.txt
```

Delete an empty directory:

```bash
rmdir linux-practice
```

Delete a directory and its contents:

```bash
rm -r linux-practice
```

**Warning:** `rm` permanently removes files in normal command-line usage. Verify the path before deleting anything. Avoid using `rm -rf` on unfamiliar paths.

### 2.6 Hidden Files and Directories

Linux files beginning with a dot (`.`) are hidden by default in ordinary directory listings.

Create a hidden file:

```bash
touch .hiddenfile
```

List hidden files:

```bash
ls -a
```

Display detailed information, including hidden files:

```bash
ls -la
```

Create a hidden directory:

```bash
mkdir .config
```

### 2.7 Searching for Files and Directories

Search for a file by name:

```bash
find /home -name "sample.txt" 2>/dev/null
```

Search for directories:

```bash
find /home -type d -name "Documents" 2>/dev/null
```

Search for text files:

```bash
find . -type f -name "*.txt"
```

Search for files modified within the last day:

```bash
find . -type f -mtime -1
```

Display directory structure:

```bash
tree
```

If tree is not installed:

```bash
sudo apt install tree
```

## 3. File Viewing and Text Processing

### 3.1 Reading Files Using cat

Display file contents:

```bash
cat sample.txt
```

Display multiple files:

```bash
cat file1.txt file2.txt
```

Create a file and add content:

```bash
cat > sample.txt
```

Type the content and press `Ctrl + D` to finish.

### 3.2 Viewing Files Using less

Display a file page by page:

```bash
less sample.txt
```

Useful navigation:
- Space: Next page.
- `b`: Previous page.
- `/word`: Search for a word.
- `q`: Exit.

### 3.3 Viewing the Beginning of Files

Display the first ten lines:

```bash
head sample.txt
```

Display the first five lines:

```bash
head -n 5 sample.txt
```

### 3.4 Viewing the End of Files

Display the last ten lines:

```bash
tail sample.txt
```

Display the last five lines:

```bash
tail -n 5 sample.txt
```

Monitor a file continuously:

```bash
tail -f /var/log/syslog
```

### 3.5 Searching Inside Files Using grep

Search for a word:

```bash
grep "Linux" sample.txt
```

Search without case sensitivity:

```bash
grep -i "linux" sample.txt
```

Display matching line numbers:

```bash
grep -n "Linux" sample.txt
```

Search recursively:

```bash
grep -r "Linux" .
```

Display lines that do not match:

```bash
grep -v "Linux" sample.txt
```

### 3.6 Sorting Data Using sort

Sort file contents alphabetically:

```bash
sort sample.txt
```

Sort in reverse order:

```bash
sort -r sample.txt
```

Sort numerically:

```bash
sort -n numbers.txt
```

### 3.7 Removing Duplicate Lines Using uniq

Remove adjacent duplicate lines:

```bash
uniq sample.txt
```

Sort and remove duplicate lines:

```bash
sort sample.txt | uniq
```

Count duplicate occurrences:

```bash
sort sample.txt | uniq -c
```

### 3.8 Counting Data Using wc

Count lines:

```bash
wc -l sample.txt
```

Count words:

```bash
wc -w sample.txt
```

Count characters:

```bash
wc -m sample.txt
```

Count bytes:

```bash
wc -c sample.txt
```

### 3.9 Extracting Data Using cut

Extract the first column:

```bash
cut -d ',' -f 1 employees.csv
```

Extract the second column:

```bash
cut -d ',' -f 2 employees.csv
```

Extract multiple columns:

```bash
cut -d ',' -f 1,3 employees.csv
```

### 3.10 Input and Output Redirection

Redirect command output into a file:

```bash
ls > output.txt
```

Append output to a file:

```bash
date >> output.txt
```

Redirect error messages:

```bash
ls /invalid-directory 2> error.txt
```

Redirect both standard output and standard error:

```bash
command > output.txt 2>&1
```

### 3.11 Pipes

Pipes send the output of one command as the input of another command.

Example:

```bash
ls -l | grep ".txt"
```

Count files:

```bash
ls | wc -l
```

Find unique sorted values:

```bash
cat sample.txt | sort | uniq
```

### 3.12 Using tee

The `tee` command displays output on the terminal and writes it to a file.

Example:

```bash
ls -la | tee directory-list.txt
```

Append output:

```bash
date | tee -a directory-list.txt
```

## 4. User and Group Management

### 4.1 Linux User Accounts

Linux is a multi-user operating system. Different users can have separate permissions and access rights.

Display the current user:

```bash
whoami
```

Display user ID and group information:

```bash
id
```

Display logged-in users:

```bash
who
```

Display user account information:

```bash
cat /etc/passwd
```

### 4.2 Primary and Secondary Groups

A primary group is the default group associated with a user.

A secondary group provides additional group membership and permissions.

Display group membership:

```bash
groups
```

Display detailed group information:

```bash
id
```

Display group database entries:

```bash
cat /etc/group
```

### 4.3 Creating Users

Create a user using adduser:

```bash
sudo adduser testuser
```

Create a user using useradd:

```bash
sudo useradd -m testuser2
```

Set the password:

```bash
sudo passwd testuser2
```

The `-m` option creates a home directory if required.

### 4.4 Deleting Users

Delete a user:

```bash
sudo userdel testuser2
```

Delete a user and their home directory:

```bash
sudo userdel -r testuser2
```

Ubuntu also provides:

```bash
sudo deluser testuser
```

Use a separate test account for practice. Never delete your main account.

### 4.5 Password Management

Set or change a user's password:

```bash
sudo passwd testuser
```

Change your own password:

```bash
passwd
```

Lock a user account:

```bash
sudo passwd -l testuser
```

Unlock a user account:

```bash
sudo passwd -u testuser
```

### 4.6 Sudo and Root Access

`sudo` allows authorized users to execute commands with elevated privileges.

Example:

```bash
sudo apt update
```

Switch to a root login shell:

```bash
sudo -i
```

Check the current user:

```bash
whoami
```

Return to the previous user:

```bash
exit
```

### 4.7 Creating and Managing Groups

Create a group:

```bash
sudo groupadd developers
```

Add a user to a secondary group:

```bash
sudo usermod -aG developers testuser
```

Check group membership:

```bash
groups testuser
```

Remove a user from a group:

```bash
sudo gpasswd -d testuser developers
```

Delete a group:

```bash
sudo groupdel developers
```

**Important:** Use `usermod -aG` to append a supplementary group. Omitting `-a` can replace the user's existing supplementary group memberships.

## 5. File Permissions and Ownership

### 5.1 Understanding Linux Permissions

Linux file permissions control who can read, write, and execute files and directories.

There are three permission categories:

| Category | Meaning |
|---|---|
| User (u) | File owner |
| Group (g) | Group associated with the file |
| Others (o) | Everyone else |

Three basic permissions:

| Permission | Symbol | Numeric Value |
|---|---|---:|
| Read | r | 4 |
| Write | w | 2 |
| Execute | x | 1 |

### 5.2 Checking File Permissions

Display file permissions:

```bash
ls -l
```

Example:

```text
-rwxr-xr--
```

Explanation:

- First character: File type.
- Next three characters: Owner permissions.
- Next three characters: Group permissions.
- Last three characters: Others permissions.

Display detailed file metadata:

```bash
stat sample.txt
```

### 5.3 Symbolic Permissions

Give the owner read, write, and execute permissions:

```bash
chmod u+rwx sample.txt
```

Give the group read permission:

```bash
chmod g+r sample.txt
```

Remove write permission from others:

```bash
chmod o-w sample.txt
```

Give everyone read permission:

```bash
chmod a+r sample.txt
```

### 5.4 Numeric Permissions

Numeric permissions are calculated using:

- Read = 4
- Write = 2
- Execute = 1

Common permission combinations:

| Permission | Owner | Group | Others | Explanation |
|---|---|---|---|---|
| 755 | 7 | 5 | 5 | Owner has full access; others can read and execute |
| 644 | 6 | 4 | 4 | Owner can read/write; others can read |
| 700 | 7 | 0 | 0 | Only the owner has access |
| 777 | 7 | 7 | 7 | Everyone has full permissions |

Apply 755:

```bash
chmod 755 script.sh
```

Apply 644:

```bash
chmod 644 sample.txt
```

Apply 700:

```bash
chmod 700 private.sh
```

Apply 777:

```bash
chmod 777 sample.txt
```

**Security note:** Avoid using 777 unless there is a specific, justified requirement. It grants read, write, and execute permissions to everyone.

### 5.5 Changing File Ownership

Change the file owner:

```bash
sudo chown testuser sample.txt
```

Change the owner and group:

```bash
sudo chown testuser:developers sample.txt
```

Change group ownership:

```bash
sudo chgrp developers sample.txt
```

Change ownership recursively:

```bash
sudo chown -R testuser:developers project-directory/
```

Use recursive ownership changes carefully, especially on system directories.

### 5.6 Understanding umask

`umask` determines which permissions are removed from the default permissions when new files and directories are created.

Display the current umask:

```bash
umask
```

Display symbolic umask:

```bash
umask -S
```

Set a temporary umask:

```bash
umask 022
```

With a typical default file mode of 666 and directory mode of 777:

- Umask 022 gives files 644 and directories 755.
- Umask 077 gives files 600 and directories 700.

Actual permissions can also be affected by application behavior and filesystem settings.

### 5.7 Special Permissions

Linux provides three additional permission mechanisms.

**SUID (Set User ID):**

An executable with SUID runs with the effective user ID of its owner.

Find SUID files:

```bash
find / -type f -perm -4000 -print 2>/dev/null
```

**SGID (Set Group ID):**

SGID on an executable runs it with the effective group ID of the file's group. On directories, it helps new files inherit the directory's group.

Find SGID files:

```bash
find / -type f -perm -2000 -print 2>/dev/null
```

**Sticky Bit:**

On a shared directory, the sticky bit restricts file deletion so that users generally can remove only files they own, or files they have appropriate administrative permissions to remove.

Example:

```bash
chmod +t shared-directory
```

Check permissions:

```bash
ls -ld shared-directory
```
