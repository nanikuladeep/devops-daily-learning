# 1. Creating, Deleting, and Moving Files

This section covers Linux filesystem operations, including creating, updating, copying, moving, deleting, and linking filesystem objects.

## 1.1 Creating and Updating File System Objects

Linux provides several commands to create files and directories and update their contents.

### Creating Files

```bash
# Create an empty file
touch file.txt

# Create multiple files
touch file1.txt file2.txt file3.txt

# Create a file using echo
echo "Welcome to Linux" > file.txt

# Create a file using cat
cat > sample.txt
```

### Creating Directories

```bash
# Create a directory
mkdir linux-practice

# Create multiple directories
mkdir dir1 dir2 dir3

# Create nested directories
mkdir -p projects/linux/practice
```

### Updating Files

```bash
# Overwrite file content
echo "Linux Learning" > file.txt

# Append content to an existing file
echo "Learning Linux commands" >> file.txt

# Display file content
cat file.txt

# Display content page by page
less file.txt

# Display the first 10 lines
head file.txt

# Display the last 10 lines
tail file.txt
```

## 1.2 Copying and Moving File System Objects

Linux uses the `cp` command to copy files and directories and the `mv` command to move or rename them.

### Copying Files

```bash
# Copy a file
cp file.txt backup.txt

# Copy a file into another directory
cp file.txt linux-practice/

# Copy multiple files
cp file1.txt file2.txt linux-practice/

# Copy a directory recursively
cp -r linux-practice backup-linux
```

### Moving Files

```bash
# Move a file
mv file.txt linux-practice/

# Move multiple files
mv file1.txt file2.txt linux-practice/

# Rename a file
mv oldname.txt newname.txt

# Rename a directory
mv old-directory new-directory
```

## 1.3 Deleting File System Objects

Linux provides commands to remove files and directories.

### Deleting Files

```bash
# Remove a file
rm file.txt

# Remove multiple files
rm file1.txt file2.txt

# Remove files interactively
rm -i file.txt
```

### Deleting Directories

```bash
# Remove an empty directory
rmdir linux-practice

# Remove a directory and its contents
rm -r linux-practice

# Forcefully remove files and directories
rm -rf backup-linux
```

**Important:** The `rm -rf` command permanently removes the specified files and directories without asking for confirmation. Always verify the target path before executing it.

## 1.4 Linking File System Objects

Linux supports two important types of links:

1. Hard Links
2. Symbolic Links (Soft Links)

### Hard Links

A hard link is another directory entry pointing to the same underlying file data (inode).

```bash
# Create a sample file
echo "Linux Hard Link Example" > original.txt

# Create a hard link
ln original.txt hardlink.txt

# Display inode information
ls -li original.txt hardlink.txt
```

### Symbolic Links

A symbolic link points to the path of another file or directory.

```bash
# Create a symbolic link
ln -s original.txt softlink.txt

# Display symbolic link information
ls -l softlink.txt

# Read symbolic link content
cat softlink.txt
```

### Hard Link vs Symbolic Link

| Hard Link | Symbolic Link |
|---|---|
| Points to the same inode | Points to a pathname |
| Cannot normally cross filesystem boundaries | Can cross filesystem boundaries |
| Usually cannot link directories | Can link directories |
| Remains valid if the original filename is removed | Can become broken if the target is removed |

# 2. Filtering Data Streams

Filtering data streams helps search, identify, and extract specific information from files and command outputs.

## 2.1 Controlling Data Streams with Wildcards

Wildcards are special characters used to match filenames and patterns.

| Wildcard | Description | Example |
|---|---|---|
| * | Matches zero or more characters | `*.txt` |
| ? | Matches exactly one character | `file?.txt` |
| [] | Matches characters inside brackets | `file[123].txt` |
| [a-z] | Matches a range of characters | `[a-z]*.txt` |

### Practical Examples

```bash
# List all text files
ls *.txt

# List files starting with app
ls app*

# List files containing exactly one character after file
ls file?.txt

# Match file1.txt, file2.txt, and file3.txt
ls file[123].txt

# Match files starting with a lowercase letter
ls [a-z]*
```

## 2.2 Using grep to Filter Search Operations

`grep` stands for Global Regular Expression Print.

It searches for specific text patterns inside files and command outputs.

### Basic Syntax

```bash
grep [options] "pattern" filename
```

### Basic Search

```bash
# Search for a specific word
grep "error" application.log

# Case-insensitive search
grep -i "error" application.log

# Display matching line numbers
grep -n "error" application.log

# Search for a complete word
grep -w "error" application.log

# Count matching lines
grep -c "error" application.log

# Display lines that do not match
grep -v "error" application.log
```

### Precision Filtering

```bash
# Search for multiple patterns
grep -E "ERROR|WARNING" application.log

# Search for lines starting with ERROR
grep "^ERROR" application.log

# Search for lines ending with failed
grep "failed$" application.log

# Search recursively inside directories
grep -r "error" .

# Display matching lines with surrounding context
grep -C 2 "error" application.log
```

### grep Special Characters

| Character | Meaning |
|---|---|
| ^ | Beginning of a line |
| $ | End of a line |
| . | Any single character |
| * | Zero or more repetitions of the preceding expression |
| [] | Character set |
| [^ ] | Negated character set |
| \ | Escape character |

### Practical Examples

```bash
grep "^INFO" application.log

grep "failed$" application.log

grep "[0-9]" application.log

grep "\." application.log

grep -E "ERROR|WARNING" application.log
```

## 2.3 Searching File Systems

Linux provides commands to search for files and directories.

### Using find

```bash
# Search for a file by name
find /home -name "file.txt"

# Search for all text files
find . -name "*.txt"

# Search for directories
find . -type d

# Search for regular files
find . -type f

# Search without considering case
find . -iname "FILE.TXT"
```

### Searching by File Size

```bash
# Find files larger than 100 MB
find . -type f -size +100M

# Find files smaller than 10 KB
find . -type f -size -10k
```

### Using locate

```bash
# Search for a file
locate file.txt

# Update the locate database (requires appropriate permissions)
sudo updatedb
```

Note: `locate` depends on an indexed database and may not immediately show newly created files.

## 2.4 Controlling Searches by Object Attributes

The `find` command supports searching based on different filesystem attributes.

### Search by File Type

```bash
# Find regular files
find . -type f

# Find directories
find . -type d

# Find symbolic links
find . -type l
```

### Search by Permissions

```bash
# Find files with permission 644
find . -type f -perm 644

# Find files with executable permissions
find . -type f -executable
```

### Search by Ownership

```bash
# Find files owned by the current user
find . -user "$USER"
```

### Search by Modification Time

```bash
# Files modified within the last 24 hours
find . -type f -mtime -1

# Files modified more than 7 days ago
find . -type f -mtime +7
```

### Search and Execute Commands

```bash
# Find and list all text files
find . -name "*.txt" -exec ls -l {} \;

# Find and delete temporary files
find . -name "*.tmp" -type f -delete
```

# 3. Editing and Manipulating Data Streams

Linux provides several utilities to sort, extract, count, and manipulate text data.

## 3.1 Ordering Data Streams Using sort

The `sort` command arranges lines in files or command outputs.

### Basic Syntax

```bash
sort filename
```

### Practical Examples

```bash
# Create sample data
printf "banana\napple\norange\nmango\n" > fruits.txt

# Sort alphabetically
sort fruits.txt

# Sort in reverse order
sort -r fruits.txt

# Sort and remove duplicate lines
sort -u fruits.txt

# Sort numerically
sort -n numbers.txt

# Sort in reverse numerical order
sort -nr numbers.txt
```

## 3.2 Parsing Data Using sort

The `sort` command supports sorting based on specific fields.

Create sample data:

```bash
cat > employees.txt <<EOF
101 John 45000
102 Alice 55000
103 David 40000
104 Smith 60000
EOF
```

### Sort by Employee ID

```bash
sort -k1 employees.txt
```

### Sort by Name

```bash
sort -k2 employees.txt
```

### Sort by Salary

```bash
sort -k3 -n employees.txt
```

### Sort by Salary in Descending Order

```bash
sort -k3 -nr employees.txt
```

### Important sort Options

| Option | Description |
|---|---|
| -r | Reverse sorting |
| -n | Numeric sorting |
| -u | Remove duplicate lines |
| -k | Specify a sorting field |
| -t | Specify a field delimiter |
| -f | Ignore case differences |

Example using comma-separated data:

```bash
sort -t ',' -k2 employees.csv
```

## 3.3 Filtering Data Streams Using cut

The `cut` command extracts specific columns or characters from each line of input.

### Basic Syntax

```bash
cut [options] filename
```

### Extract Fields

Create a sample CSV file:

```bash
cat > employees.csv <<EOF
101,John,45000
102,Alice,55000
103,David,40000
EOF
```

```bash
# Extract the first field
cut -d ',' -f1 employees.csv

# Extract the second field
cut -d ',' -f2 employees.csv

# Extract multiple fields
cut -d ',' -f1,3 employees.csv

# Extract a range of fields
cut -d ',' -f1-2 employees.csv
```

### Extract Characters

```bash
# Display the first five characters
cut -c1-5 employees.csv

# Display the first three characters
cut -c1-3 employees.csv
```

### Important cut Options

| Option | Description |
|---|---|
| -d | Specifies delimiter |
| -f | Selects fields |
| -c | Selects characters |
| --complement | Selects everything except specified fields |

## 3.4 Quantifying Data Stream Attributes Using wc

The `wc` command counts lines, words, characters, and bytes.

### Basic Syntax

```bash
wc filename
```

### Practical Examples

```bash
# Count lines, words, and bytes
wc file.txt

# Count lines
wc -l file.txt

# Count words
wc -w file.txt

# Count bytes
wc -c file.txt

# Count characters
wc -m file.txt

# Display the longest line length
wc -L file.txt
```

### Using wc With Other Commands

```bash
# Count the number of files in the current directory
ls -1 | wc -l

# Count matching ERROR lines
grep "ERROR" application.log | wc -l

# Count all running processes
ps aux | wc -l
```

# 4. Redirecting Data Streams

Redirection allows Linux commands to send their output to files or receive input from files.

## 4.1 Appending Data Streams to Files

Linux uses redirection operators to manage command output.

### Overwriting File Content

```bash
echo "Linux Learning" > file.txt
```

The `>` operator creates a file or overwrites existing content.

### Appending File Content

```bash
echo "Learning Linux Commands" >> file.txt
```

The `>>` operator appends data without removing existing content.

### Redirect Command Output

```bash
ls -l > files.txt
```

### Append Command Output

```bash
date >> files.txt
```

### Read Input From a File

```bash
sort < fruits.txt
```

The `<` operator redirects file content to a command's standard input.

## 4.2 Understanding Standard Input, Standard Output, and Standard Error

Linux uses three standard data streams.

| Stream | File Descriptor | Description |
|---|---|---|
| Standard Input | 0 | Input received by a command |
| Standard Output | 1 | Normal command output |
| Standard Error | 2 | Error messages |

### Standard Input (stdin)

Standard input receives data from the keyboard or another command.

```bash
cat < file.txt
```

### Standard Output (stdout)

Standard output displays normal command results.

```bash
ls -l
```

Redirect stdout into a file:

```bash
ls -l > output.txt
```

### Standard Error (stderr)

Standard error displays error messages.

```bash
ls /invalid-directory
```

Redirect error messages:

```bash
ls /invalid-directory 2> errors.txt
```

### Redirect stdout and stderr Separately

```bash
command > output.txt 2> errors.txt
```

### Redirect Both stdout and stderr

```bash
command > all-output.txt 2>&1
```

Alternatively:

```bash
command &> all-output.txt
```

### Discard Error Messages

```bash
command 2> /dev/null
```

### Discard All Output

```bash
command > /dev/null 2>&1
```

## 4.3 Chaining Multiple Commands

Linux allows multiple commands to be executed together.

### Using Semicolon (;)

Executes the next command regardless of whether the previous command succeeds or fails.

```bash
mkdir project; cd project; touch README.md
```

### Using AND Operator (&&)

Executes the next command only if the previous command succeeds.

```bash
mkdir project && cd project && touch README.md
```

### Using OR Operator (||)

Executes the next command only if the previous command fails.

```bash
mkdir project || echo "Directory creation failed"
```

### Using Pipe Operator (|)

Sends the output of one command as input to another command.

```bash
ls -l | grep ".txt"
```

### Combining Multiple Commands

```bash
ps aux | grep python | sort -k3 -nr
```

This command filters Python processes and sorts the results based on the third column in descending numerical order.

## 5.2 Explore Linux File System Directories, Disks, and Partitions

### Objective

Understand the Linux filesystem hierarchy and learn how to inspect disks, partitions, and mounted filesystems.

### Important Linux Directories

| Directory | Purpose |
|---|---|
| / | Root directory |
| /home | User home directories |
| /root | Root user's home directory |
| /etc | System configuration files |
| /bin | Essential user commands |
| /sbin | System administration commands |
| /var | Variable data and logs |
| /tmp | Temporary files |
| /usr | User applications and resources |
| /boot | Boot-related files |
| /dev | Device files |
| /proc | Process and kernel information |
| /sys | Kernel and device information |
| /mnt | Temporary mount point |
| /media | Removable media mount points |

### Filesystem Exploration Commands

```bash
# Display current directory
pwd

# List root directory
ls /

# List files with details
ls -lah

# Display directory structure
tree /

# Display filesystem disk usage
df -h

# Display filesystem types
df -Th

# Display directory sizes
du -sh /home

# Display block devices
lsblk

# Display disk and partition information
sudo fdisk -l

# Display mounted filesystems
findmnt

# Display mount information
mount
```

Note: `tree` may need installation using `sudo apt install tree`. Commands such as `fdisk -l` require administrator privileges.

### Key Learning

- Explored the Linux filesystem hierarchy.
- Understood the purpose of important system directories.
- Learned to inspect available disks and partitions.
- Understood filesystem mounting and disk usage commands.

## 5.3 Become Familiar with Shell Variables

### Objective

Understand shell variables, environment variables, and how variables can be created, accessed, modified, and exported.

### Creating Variables

```bash
# Create a variable
name="Linux"

# Display variable value
echo $name

# Create another variable
course="DevOps"

# Display variable values
echo "Learning $course with $name"
```

### Environment Variables

```bash
# Display current user
echo $USER

# Display home directory
echo $HOME

# Display current shell
echo $SHELL

# Display current working directory
echo $PWD

# Display PATH variable
echo $PATH

# Display all environment variables
printenv
```

### Exporting Variables

```bash
# Create a variable
project="DevOps Learning"

# Export the variable
export project

# Display the variable
echo $project
```

Exported variables are available to child processes started by the shell.

### Removing Variables

```bash
unset project
```

### Displaying Variables

```bash
# Display all shell variables
set

# Display environment variables
env

# Display a specific variable
printenv HOME
```

### Command Substitution

```bash
# Store current date
today=$(date)

# Display stored date
echo "$today"
```

### Key Learning

- Understood shell variables.
- Learned how to create and access variables.
- Explored environment variables.
- Practised exporting and removing variables.
